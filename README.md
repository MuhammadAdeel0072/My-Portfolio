## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/MuhammadAdeel0072/Adeel-Portfolio.git
   cd Adeel-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

## 🎨 Customization

### Change Colors
Edit the Tailwind config in `tailwind.config.js` to customize the color scheme.

### Add/Edit Projects
Modify the `projects` array in `src/components/Projects.jsx`

### Update Skills
Edit the `skillCategories` array in `src/components/Skills.jsx`

### Change Contact Info
Update contact details in `src/components/Contact.jsx`

### Add Profile Picture
Replace/update `src/assets/Portfolio.jpeg` with your image
