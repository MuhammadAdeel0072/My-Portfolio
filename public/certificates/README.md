# Certificate PDFs

Drop the real certificate PDF files into this folder to enable the inline
PDF preview in the Certificates section. Use these exact filenames
(they match the `file` paths in `src/components/portfolio/Certificates.jsx`):

1. `IOT Certifcate.pdf`          — Introduction to IoT (Cisco Networking Academy)
2. `C++ Essential 2.pdf`         — C++ Essential 2 / OOP (Cisco Networking Academy)
3. `C++ Advance.pdf`             — C++ Advanced / Data Structures (Cisco Networking Academy)
4. `IT Essential.pdf`            — IT Essentials (Cisco Networking Academy)
5. `DB.Certificate.pdf`          — SQL and Relational Databases (CognitiveClass.ai)
6. `Engagging StakeHolders.pdf`  — Engaging Stakeholders (Business Professional)
7. `Enterpreneurships.pdf`       — Discovering Entrepreneurship (Business Professional)

While a file is missing, the certificate modal shows a graceful fallback panel
instead of a broken viewer.
